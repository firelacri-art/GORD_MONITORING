# Запуск: командой и по расписанию

## Командой

Установлен как плагин:

```
/gord-monitoring:gord-monitoring yoomoota
/gord-monitoring:gord-monitoring yoomoota --days 7
/gord-monitoring:gord-monitoring новый проект "Моремания: открытие террасы"
```

Скопирован в `~/.claude/skills`: то же самое без префикса — `/gord-monitoring yoomoota`.
Обычная фраза тоже работает: «проверь публикации по Yoomoota за неделю»,
«обнови мониторинг Моремании», «найди, кто написал про аукцион Novikov».

Первый запуск проекта: Claude создаёт `~/.gord-monitoring/<slug>/project.json`
(инфоповод, запросы, watchlist'ы) по образцу `scripts/examples/yoomoota.json` и
спрашивает только то, что не выводится из запроса.

## По расписанию

Мониторинг делится на две части с разной частотой:

| Часть | Что нужно | Частота | Где запускать |
| --- | --- | --- | --- |
| СМИ + Telegram-watchlist (скрипты, без браузера) | ключи API по желанию | ежедневно утром | планировщик приложения Claude Code (Mac/Windows) или облачная routine (`/schedule`) |
| Instagram, TikTok, Telegram Web, поиск через браузер | залогиненный браузер пользователя | 2–3 раза в неделю; сторис — ежедневно | только планировщик приложения на компьютере, где открыт Chrome с расширением Claude |

Облачные routines не видят браузер пользователя, поэтому соцсети через них не
проверяются. Для них планировщик на локальной машине: компьютер включён, Chrome
открыт, аккаунты залогинены.

### Пример задач планировщика

- **«gord-monitoring: СМИ»**, ежедневно 09:30:
  «Запусти навык gord-monitoring для всех проектов из ~/.gord-monitoring (только
  скриптовые источники), разбери новых кандидатов, обнови таблицы мониторинга и
  пришли сводку: сколько новых публикаций, где нет AVE/OTS, что требует ручной проверки.»
- **«gord-monitoring: соцсети»**, пн/ср/пт 11:00:
  «Запусти навык gord-monitoring для проекта yoomoota, часть «браузер»: Instagram
  (отметки бренда, watchlist, сторис), TikTok-поиск, Telegram Web. Не больше 20 страниц
  на сервис. Если капча или просьба войти — остановись и напиши.»

Создаются через `/schedule` (облако) либо через планировщик в приложении. Cron-вариант
для сервера без приложения: `claude -p "/gord-monitoring:gord-monitoring yoomoota"`
(нужен установленный CLI и выполненный `claude auth login`).

## Куда попадает результат

- `~/.gord-monitoring/<slug>/entries.json` — источник правды, копится между запусками.
- `~/.gord-monitoring/<slug>/Мониторинг публикаций — <проект>.xlsx` — лист в стиле
  GORD, пересобирается целиком при каждом запуске (`build_monitoring_sheet.py`).
- CSV рядом (`--csv`) — для вставки новых строк в существующую Google-таблицу
  партнёра: открыть CSV, скопировать строки → вставить в нужный месяц. Или импорт
  xlsx новым листом (Файл → Импортировать → «Вставить новые листы»). Если в сессии
  есть браузер с Google-аккаунтом, Claude может вставить строки сам — с подтверждением.
- Сводка в чат: новые публикации, суммы AVE/OTS за период, список «уточнить».
