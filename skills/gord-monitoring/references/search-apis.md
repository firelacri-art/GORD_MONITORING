# Источники поиска по СМИ и ключи API

`search_media.py` сам включает источники, для которых есть ключи. Без ключей работают
Google News RSS, DuckDuckGo и Telegram-превью каналов — этого хватает для первого
прогона. Для полноты, сравнимой с ручным поиском «Google + Яндекс с фильтром по дате»,
нужны два ключа. Кладутся в файл `~/.gord-monitoring/.env`:

```
GOOGLE_CSE_KEY=AIza…
GOOGLE_CSE_CX=0123456789abcdef0
YANDEX_SEARCH_API_KEY=AQVN…
YANDEX_SEARCH_FOLDER_ID=b1g…
```

Файл читают все скрипты навыка. В репозиторий ключи не попадают никогда.

## Google Custom Search JSON API (бесплатно до 100 запросов в день)

1. https://programmablesearchengine.google.com/ → «Добавить» → «Искать во всём интернете»
   (переключатель «Search the entire web») → создать. Скопировать **Идентификатор
   поисковой системы** → `GOOGLE_CSE_CX`.
2. https://console.cloud.google.com/ → проект → «API и сервисы» → включить **Custom
   Search API** → «Учётные данные» → «Создать ключ API» → `GOOGLE_CSE_KEY`.
3. Скрипт передаёт `dateRestrict=dN` (последние N дней) и `sort=date` — аналог
   ручного фильтра «за месяц». Один инфоповод = 3–4 запроса × 2 страницы; 100 запросов
   в день хватает на 10+ проектов. Больше — платно ($5 за 1 000).

## Yandex Search API (Yandex Cloud)

1. https://console.yandex.cloud/ → создать каталог (folder) → скопировать его ID →
   `YANDEX_SEARCH_FOLDER_ID`.
2. Сервисный аккаунт с ролью `search-api.webSearch.user` → «Создать API-ключ» →
   `YANDEX_SEARCH_API_KEY`.
3. Скрипт вызывает `POST https://searchapi.api.cloud.yandex.net/v2/web/search`
   с оператором `date:>ГГГГММДД` и сортировкой по свежести. Тариф: первые запросы
   бесплатны по квоте, дальше ~0,5 ₽ за запрос — на мониторинг это копейки.
4. Если ответ «HTTP 403» — не выдана роль сервисному аккаунту; «HTTP 429» — квота,
   повторить через час.

## Что делает каждый источник

| Источник | Ключ | Что покрывает | Слабые места |
| --- | --- | --- | --- |
| Google News RSS | нет | новостные сайты, точная дата | только «новостные» издания, не все lifestyle-медиа |
| DuckDuckGo | нет | индекс Bing, фильтр день/неделя/месяц | нет даты в выдаче (берём со страницы), меньше русских СМИ |
| Google CSE | да | то же, что ручной Google | 100/день бесплатно |
| Yandex Search API | да | то же, что ручной Яндекс, лучший для RU | нужен аккаунт Yandex Cloud |
| t.me/s/&lt;канал&gt; | нет | посты заданных Telegram-каналов с датой и просмотрами | только каналы из watchlist |
| Браузер (Яндекс/Google/соцсети) | вход пользователя | всё остальное | капчи, ручной темп; см. browser-channels.md |

## Запросы

В `project.json` поле `queries` — 3–5 формулировок инфоповода, как их напишут журналисты:
название бренда латиницей и кириллицей, «бренд + событие», «бренд + площадка»,
имя первого лица. Поле `keywords` — короткие маркеры для проверки текста страницы
(бренд латиницей/кириллицей). `exclude_domains` — сайт клиента и агентства, чтобы
свои же анонсы не попадали в мониторинг.
