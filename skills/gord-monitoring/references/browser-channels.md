# Каналы, которые проверяются через браузер: Instagram, Telegram Web, TikTok, Яндекс, Google

Скрипты без браузера закрывают СМИ (Google News, DuckDuckGo, при ключах Google CSE и
Яндекс API) и Telegram-каналы из watchlist (публичные превью `t.me/s/…`). Всё, что
требует входа в аккаунт или живого интерфейса, делается **через браузер пользователя**,
где он уже залогинен: расширение «Claude in Chrome» (`mcp__claude-in-chrome__*`) или
встроенная панель браузера (`mcp__Claude_Browser__*`). Логин, пароли, коды из SMS,
капчи — только сам пользователь. Если увидел капчу, проверку «вы не робот», просьбу
войти или подтвердить телефон — остановись, сделай скриншот и передай пользователю.

## Общие правила для всех каналов

- Работать **медленно, как человек**: не больше 15–25 страниц за прогон в одном
  сервисе, пауза 3–6 секунд между открытиями, никаких параллельных вкладок на один сайт.
  Быстрый прогон = блокировка аккаунта партнёра, это дороже пропущенной публикации.
- Читать страницу через `read_page` / `find` / `get_page_text`, а не по координатам
  скриншота: интерфейсы меняются, текст стабильнее.
- Фиксировать для каждой находки: URL публикации (полный, без хвостов `igsh`, `utm`),
  автор/канал, дата, формат (пост / сторис / рилс / видео), охват если виден
  (просмотры/лайки), цитату с упоминанием. Потом `add_entry.py --url … --format … --views …`.
- Все ссылки из соцсетей проверять по `seen.json` перед открытием, чтобы не листать
  одно и то же каждый день.
- Ничего не лайкать, не комментировать, не подписываться, не писать в директ.
  Просмотр сторис виден автору как просмотр от аккаунта агентства — это нормально
  для PR-мониторинга, но пользователь должен об этом знать (написано в README).

## Instagram (`instagram.com`, нужен вход; из РФ — VPN)

Ключевого поиска по тексту постов у Instagram нет, поэтому три приёма:

1. **Отметки бренда.** `https://www.instagram.com/<brand_account>/tagged/` — посты, где
   отмечен аккаунт клиента (`brand_accounts.instagram` в project.json). Самый точный
   источник: блогер отметил бренд → почти всегда публикация про нас.
2. **Watchlist блогеров** (`instagram_watchlist`): для каждого хэндла
   - открыть `https://www.instagram.com/<handle>/` → верхние 6–9 постов сетки → открыть те,
     что по дате попадают в период (дата видна в открытом посте) → прочитать подпись,
     отмеченные аккаунты, хэштеги → ищем ключевые слова проекта или отметку бренда;
   - сторис: `https://www.instagram.com/stories/<handle>/` → пролистать (стрелка вправо /
     `find` «Next») → искать упоминание, стикер-ссылку, отметку `@brand`. Сторис живут
     24 часа: если мониторинг сторис нужен, прогон должен быть **ежедневным**. Ссылку на
     конкретную сторис взять из адресной строки (`/stories/<handle>/<id>/`); если она
     уже исчезла, в таблицу пишется ссылка на профиль и формат «сторис» с датой.
3. **Поиск по словам и хэштегам** (менее надёжен): `https://www.instagram.com/explore/search/keyword/?q=<запрос>`
   и `https://www.instagram.com/explore/tags/<хэштег>/` (без пробелов и спецсимволов).
   Смотреть только вкладку «Недавние», ограничиться 2 экранами прокрутки.

Охват: для постов/рилс — число просмотров или лайков на странице поста; для сторис
охват не виден → берём OTS блогера из справочника площадок (`media-reference.csv`).

## Telegram Web (`web.telegram.org`, нужен вход)

- **Поиск по публичным постам.** В поле поиска ввести инфоповод. Если в результатах есть
  вкладка «Публикации» / «Posts» / «Public posts» — это глобальный поиск по всем открытым
  каналам, именно то, что нужно: пройти список, для каждого совпадения открыть пост
  (правый клик / «Copy post link» или из адресной строки `#@канал/ID` → превращаем в
  `https://t.me/<канал>/<ID>`), зафиксировать канал, дату, просмотры (число рядом с глазом).
  Вкладка доступна аккаунтам с Telegram Premium; без Premium её может не быть — тогда
  сообщить пользователю: «нужен Premium на рабочем аккаунте или подписка TGStat».
- **Без Premium:** поиск в Telegram Web находит только каналы и чаты **по названию** и
  сообщения в чатах, где аккаунт уже состоит. Рабочая замена — watchlist каналов в
  `project.json` (`telegram_watchlist`): их читает `search_media.py` без браузера через
  публичные превью `t.me/s/<канал>`, включая дату и просмотры. Дополняй watchlist
  каналами блогеров и СМИ, с которыми агентство работает.
- **TGStat** (`https://tgstat.ru/search?q=<запрос>`), если у агентства есть аккаунт:
  вкладка «Публикации», фильтр по дате, каждая находка даёт канал, дату, просмотры и
  прямую ссылку `t.me/…`. Открывать через тот же браузер пользователя.

## TikTok (`tiktok.com`, вход желателен, но поиск открыт)

- Поиск: `https://www.tiktok.com/search?q=<запрос>` → вкладка «Видео» → фильтр
  «Дата публикации» (кнопка «Фильтры» над результатами): «На этой неделе» / «В этом
  месяце». Прокрутить 2–3 экрана. Для каждого видео из периода: открыть, прочитать
  описание и хэштеги, зафиксировать URL `https://www.tiktok.com/@<автор>/video/<id>`,
  автора, дату (под описанием), просмотры (число под кнопкой ▶ или в карточке).
- Watchlist авторов (`tiktok_watchlist`): `https://www.tiktok.com/@<handle>` → последние
  6–9 видео → те, что по дате в периоде.
- Короткие ссылки `tiktok.com/t/…` разворачивать: открыть и взять URL из адресной строки.

## Яндекс и Google через браузер (когда нет ключей API)

- Яндекс: `https://yandex.ru/search/?text=<запрос>&within=77` (`within=77` — за месяц,
  `within=7` — неделя, `within=1` — сутки; при сомнениях включить фильтр «За месяц» в
  расширенном поиске вручную и скопировать URL). Пройти 2–3 страницы, вкладку
  «Новости» отдельно: `https://yandex.ru/news/search?text=<запрос>` (при доступности).
  Сохранять только результаты с датой в периоде.
- Google: `https://www.google.com/search?q=<запрос>&tbs=qdr:m&hl=ru` (`qdr:w` неделя,
  `qdr:m` месяц) и вкладка «Новости» (`&tbm=nws`).
- Появилась капча или «Подтвердите, что вы не робот» → остановиться и сказать
  пользователю; не пытаться обойти и не повторять запросы подряд. В следующий раз
  добавить ключи API (см. `search-apis.md`) — это убирает капчи полностью.

## Как оформить найденное

```bash
# пост блогера в Instagram, охват из справочника
python3 add_entry.py yoomoota --url "https://www.instagram.com/p/DXjXPcfjbAs" --format пост --name veta.savva --date 2026-09-06
# сторис (ссылка на профиль, если сама сторис уже недоступна)
python3 add_entry.py yoomoota --url "https://www.instagram.com/stories/rul.bomond/" --format сторис --date 2026-09-05
# видео TikTok с просмотрами
python3 add_entry.py yoomoota --url "https://www.tiktok.com/@katya.og2000/video/7411…" --format видео --views 47400 --date 2026-09-07
# пост в Telegram
python3 add_entry.py yoomoota --url "https://t.me/oimaskva/7391" --format пост --views 7700 --date 2026-09-04
```
