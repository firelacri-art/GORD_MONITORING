# Формат публикации, AVE и OTS

## Форматы (колонка «Формат»)

Значения — как в таблицах агентства, строчными:

| Формат | Когда ставить |
| --- | --- |
| `экспертная статья` | материал построен на комментарии/экспертизе первого лица или бренда; инфоповод — основа текста |
| `моно-статья` | вся статья только про наш инфоповод (анонс события, обзор коллаборации) |
| `новость` | короткая заметка (до ~2 000 знаков) про инфоповод |
| `подборка` | «10 мест / что нового в ресторанах»: наш инфоповод — один из пунктов |
| `дайджест` | обзор недели/событий, где нас упомянули абзацем |
| `упоминание` | одно предложение или ссылка внутри текста на другую тему |
| `пост` | пост в Telegram / Instagram / VK |
| `сторис` | Instagram-сторис (ссылка на сторис или на профиль + дата) |
| `рилс` | Instagram Reels |
| `видео` | TikTok / YouTube Shorts |
| `конкурс` | розыгрыш/конкурс с упоминанием бренда |

Как решить по данным `fetch_page.py`: `mentions_per_1000_words` ≥ 15 и упоминание в
заголовке → моно-статья или экспертная статья (экспертная, если есть цитаты спикера);
заголовок формата «что нового / куда сходить / N мест» → подборка или дайджест;
1–2 упоминания на длинный текст → упоминание; текст < 300 слов → новость. Если по
тексту не понятно — оставить формат пустым и написать в `--note "уточнить формат"`,
а не угадывать.

## AVE и OTS

- **AVE** (стоимость) — эквивалент рекламной стоимости публикации на этой площадке.
- **OTS** (охват) — аудитория площадки/автора, у которой была возможность увидеть материал.

У агентства это **справочник по площадкам**, а не расчёт по каждой статье: у одной
площадки одинаковые AVE/OTS во всех строках (gazeta.ru → 150 000 / 110 300 000). Поэтому:

1. `assets/media-reference.csv` — стартовый справочник (≈90 площадок из мониторингов
   агентства: СМИ по домену, Telegram/Instagram/TikTok по хэндлу). `add_entry.py`
   подставляет значения автоматически, если площадка найдена.
2. Дополнения агентства — в `~/.gord-monitoring/media-reference.csv` с теми же
   колонками (`channel,key,name,ave,ots,formats_seen`); они имеют приоритет над
   стартовым файлом. Новую площадку добавляй туда, как только менеджер назвал цифры.
3. Площадка не найдена → в записи `ave`/`ots` пустые и пометка «[уточнить AVE/OTS]» в
   колонке «Комментарий». **Не выдумывать цифры** и не подставлять «похожие площадки».
4. Для соцсетей охват поста (просмотры) фиксируется отдельно в `views`; в OTS идёт
   аудитория автора из справочника, как принято у агентства. Если менеджер хочет
   OTS = просмотры поста, он правит правило в своём справочнике.

Числа в таблице — с разрядкой пробелом (формат `#,##0`, в русской локали Excel и
Google Sheets это пробел): `110 300 000`.
